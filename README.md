# Eco Explorer

# Green Business Model

## Interactive Exhibition Website

> "Scan. Explore. Learn."

---

# Project Goal

The physical model demonstrates the idea of a Green Business.

The website acts as a digital extension of the model.

Visitors scan a QR code placed beside the project.

↓

The website opens instantly.

↓

The website automatically guides the visitor through every part of the project using animations, interactive diagrams and illustrations.

Instead of reading long paragraphs, the visitor experiences the project.
